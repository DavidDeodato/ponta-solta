# Ponta Solta

Uma entrevista de emprego por vídeo fica cada vez mais absurda. Você inventa explicações para o que aparece na sua webcam e precisa fazer cada resposta bater com o que já disse. A entrevistadora lembra dos detalhes e pode voltar a eles até o fim da chamada.

Projeto do módulo Experiências Imersivas do Inteli.
